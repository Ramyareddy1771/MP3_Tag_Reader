# MP3_Tag_Reader
MP3 tag reader is a software which will read &amp;display MP3 (ID3) tag info from MP3 files. The software will be desktop based, not web based. This solution will read given MP3 file, extract various tag info&amp; display them via command line.This project can be extended to implement tag editor, where-in users can modify mp3 tag info. ID3v2 Version: 2.3.0
